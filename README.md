## 📌 About This Repository

This repository contains a collection of SQL tasks completed as part of the **Calibo training/assessment activities**.

The tasks cover important SQL concepts such as:

- Database and table creation
- Data insertion and manipulation
- Filtering and conditional queries
- Aggregate functions
- Grouping and sorting
- INNER JOIN
- SELF JOIN
- Subqueries
- Table modification
- Department-wise analysis

---

## 📂 Tasks

### 🏫 Task 1 – College Management

**File:** `CollegeManagement_T1.sql`

This task focuses on creating and working with a college management database.

**Concepts Covered:**

- Database creation
- Student table creation
- Inserting student records
- `SELECT`
- `WHERE`
- `ALTER TABLE`
- `DESC`
- Department table
- `INNER JOIN`

- Student-course enrollment analysis
